# JP225 事件推播 Telegram Bot

把 Pine 指標「日經 時段+事件 Pro v9」的功能搬到 Telegram。

## 為什麼要搬出 TradingView

| 功能 | Pine | 這支 Bot |
|---|---|---|
| 事件時間表 | ✅ | ✅ |
| 波動跳升 % | ✅ | ✅ |
| 市場反應（事件後漲跌） | ✅ | ✅ |
| **事前主動提醒** | ❌ 要盯著圖 | ✅ 推到手機 |
| **真新聞 + 情緒** | ❌ Pine 無 HTTP | ✅ 選用 |

**Pine Script 沒有任何讀取新聞的能力**（無 HTTP、無外部 API），
這是唯一能同時做事件推播與新聞的路。

---

## 安裝（三步）

### 1. 建立 Telegram Bot

1. Telegram 搜尋 **@BotFather** → `/newbot` → 取得 **token**
2. 對你的新 bot 傳一則訊息（隨便什麼都行）
3. 瀏覽器開 `https://api.telegram.org/bot<你的token>/getUpdates`
   → 找到 `"chat":{"id":123456789}` 那組數字，就是 **chat_id**

### 2. 填設定檔

第一次執行會自動產生 `config.json`：

```bash
python bot.py
```

打開 `config.json` 填入：

```json
{
  "telegram_bot_token": "貼上你的 token",
  "telegram_chat_id": "貼上你的 chat id"
}
```

> Token 請自己貼進檔案，不要傳給任何人（包含我）。

### 3. 執行

```bash
python bot.py
```

啟動時會先推一則今日事件表確認連線正常。

## 設定項目

| 欄位 | 預設 | 說明 |
|---|---|---|
| `symbol` | `^N225` | Yahoo 代號。日經現貨指數 |
| `is_dst` | `true` | 歐美夏令時間。**11 月初～3 月中要改成 `false`** |
| `pre_alert_min` | `10` | 事件前幾分鐘提醒 |
| `reaction_min` | `30` | 事件後幾分鐘回報市場反應 |
| `daily_digest_at` | `"07:00"` | 每日事件表推播時間（台北） |
| `poll_seconds` | `30` | 檢查頻率 |
| `enable_news` | `false` | 是否啟用新聞 |
| `news_api_key` | `""` | newsapi.org 免費 key |

## 新聞功能（選用）

1. 到 [newsapi.org](https://newsapi.org) 註冊免費 key（每日 100 次請求）
2. `config.json` 設 `"enable_news": true` 並填 `news_api_key`

每日摘要時會附上近 6 小時日股相關新聞與情緒標記。

**⚠️ 情緒判定是關鍵字比對，不是 NLP 模型。** 我用透明的方式做而不是包裝成
「AI 情緒分析」—— 它只是掃描標題裡的正負面詞彙，會誤判反諷、否定句、
以及已被 price in 的消息。當快速掃描用，不要當訊號。

未啟用或 API 失敗時會回空清單，**不會編造新聞內容**。

## 已知限制

1. **事件時間是固定時刻，不是真實日曆。** CPI 一個月一次、FOMC 一年八次，
   但 20:30 和 02:00 每天都會提醒。它標的是「這時間可能有事」。
   要精確知道今天有沒有，仍需查財經日曆。

2. **`^N225` 是現貨指數**，只有日本盤時段有報價。歐美時段的「市場反應」
   會抓到上一筆收盤價而算出 0。要涵蓋夜盤請改用期貨或 CFD 代號。

3. **跳升 % 來自 2026-04~08 的單一期間**。跨制度未驗證 ——
   同樣的數字在 2021、2023 可能完全不同（時段方向已被證實跨期間不穩）。

4. **這不是交易訊號。** 它告訴你「什麼時候波動會放大」，
   不告訴你「該做多還做空」。方向那一層我測過，跨制度全滅。
